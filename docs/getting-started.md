# Getting Started

## Install
```
npm install
```

## Validate
```
npm run validate
```

## Test
```
npm run test
```

## List skills
```
npm run list
```

## Search
```
npm run search -- "design systems"
```

## Inspect
```
npm run inspect -- design-system-architect
```

## Use skills
Copy or reference `skills/` in your agent runtime that supports Agent Skills. For runtimes without native multi-agent support, invoke skills individually per task.
