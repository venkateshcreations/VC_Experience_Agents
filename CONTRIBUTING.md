# Contributing

## Adding a skill

1. Create `skills/<group>/<skill-name>/SKILL.md`.
2. Follow `docs/skill-authoring.md`.
3. Add entry to `resources/skill-catalog.json`.
4. Add test case in `tests/skills/`.
5. Run `npm run validate && npm run test`.

## External resources

Record provenance and license before import. See `docs/source-governance.md`.

## Pull requests

Keep changes focused. Include test results.
